CAREPOINT - ONLINE DOCTOR APPOINTMENT SYSTEM

HOW TO RUN (Windows + VS Code)
1. Extract the ZIP file.
2. Open the CarePoint_Online_Doctor_Appointment folder in Visual Studio Code.
3. Open Terminal > New Terminal.
4. Type: node server.js
5. Open http://localhost:3000 in your browser.

REQUIREMENTS
- Node.js 18 or newer
- No npm install required
- Internet connection for doctor photos and web fonts

FEATURES
- Responsive CarePoint design with doctor photos
- Six doctors and specialty filters
- Search by doctor name or specialty
- Appointment booking form
- Appointment list and cancellation
- Appointment data stored in data/appointments.json

This is a student demo, not a real medical service. Keep the terminal open while using the website. Press Ctrl+C to stop it.
